IMKAS PROJECT SITE
==================

Files:
- index.html
- style.css
- assets/github.png
- assets/discord.png

WHAT TO EDIT
------------

1. Open index.html in any text editor.

2. Replace each:
   href="#"

   with the correct GitHub or Discord URL.

Example:
   <a href="https://github.com/YOUR-NAME/YOUR-REPO" ...>

3. Change the project descriptions if desired.

4. The included GH/DC PNGs are simple placeholders.
   You can replace them later with any GitHub/Discord PNG you want.
   Keep the filenames:
   - assets/github.png
   - assets/discord.png

LOCAL TESTING
-------------

Double-click index.html to open it in your browser.

GITHUB PAGES
------------

Upload the contents of this folder to the root of a GitHub repository.

Then in the repository:
Settings -> Pages
Source: Deploy from a branch
Branch: main
Folder: / (root)
Save

GitHub will then publish the site and show its URL in the Pages settings.
